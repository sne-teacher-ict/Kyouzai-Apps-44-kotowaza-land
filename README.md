# ことわざランド v4

ことわざを複数の異なる操作で学べる、ブラウザだけで動くWeb教材です。

## v4 の変更
- 収録ことわざを **20個 → 40個** に増加
- 「ばめんさがし」の各場面カードに **アプリ内SVGイラスト** を追加
  - 外部画像・画像生成は使用していません
  - SVGはHTML/JavaScript内で図形として描画します
- 場面カードの文章に **ふりがな** を追加
- 通常問題数を **5 / 10 / 20 / 30 / 40問** から選択可能
- 同じことわざを同一セット内で重複出題しない仕様に変更
- チャレンジマップを **5問 → 最大10問** に拡張
- 初期問題数を10問に変更

## 学習モード
- ことわざカード：カードをめくって意味を確認
- いみクイズ：ことわざの意味を選択
- ばめんさがし：SVGイラスト＋場面文から合うものを探す
- ことわざパズル：後半カードをタップ／ドラッグして完成
- チャレンジマップ：複数形式を混ぜて最大10問
- 先生モード：難易度・問題数・出題することわざ・ふりがな・読み上げを設定

## 起動
ZIPを展開して、直下の `index.html` をブラウザで開いてください。
